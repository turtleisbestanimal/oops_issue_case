# OoPs 사례 관리 — Vercel 배포용

## 구성

- `public/index.html`: 전체 123건, 7가지 요소 편집, 상태 변경, 휴지통, 백업을 포함한 단일 HTML
- `vercel.json`: 빌드 없이 public 폴더를 서비스하는 설정

## Vercel 배포

1. 이 폴더의 `public` 폴더와 `vercel.json`을 GitHub 저장소에 올립니다.
2. Vercel에서 해당 저장소를 Import합니다.
3. Root Directory는 이 폴더 기준, Framework Preset은 **Other**, Build Command는 **빈칸**, Output Directory는 **public**으로 설정합니다. 포함한 vercel.json에도 설정되어 있습니다.
4. Deploy를 누릅니다. 설치할 패키지나 환경 변수는 없습니다.

CLI를 사용하는 경우 이 폴더에서 `npx vercel --prod`를 실행하고 본인 계정으로 연결합니다. 실제 배포는 이 파일 묶음에 포함되어 있지 않습니다.

## 기능

- 편집 시작 → 사례를 펼쳐 7가지 요소 본문 수정 → 편집 완료
- 각 사례 제목 아래 **확인 상태 변경** 메뉴에서 상태 선택. 사례를 펼치거나 편집 모드를 켜지 않아도 변경할 수 있습니다. **새 상태 직접 입력…**으로 상태 이름 추가 가능
- **확인 상태 필터 → 유형 관리**에서 유형을 추가·삭제합니다. 사용하지 않는 유형도 0건으로 유지됩니다. 사용 중인 유형을 삭제할 때는 휴지통을 포함한 사례를 옮길 다른 상태를 선택합니다. 최소 한 가지 유형은 유지합니다.
- 휴지통으로 이동 → 휴지통 탭에서 삭제 시각·내용 확인 → 사례 복원
- 삭제 시 사례 번호는 변경되지 않습니다. 휴지통의 **영구 삭제** 버튼에서 확인 후 본문·출처·변경 기록을 제거할 수 있습니다. 영구 삭제한 사례는 휴지통에서 복원할 수 없습니다.
- 상태·삭제·복원 변경 기록은 각 사례 하단에서 확인합니다.
- 이름, 새 번호, 원래 ID와 수정한 내용으로 검색. 휴지통에서도 검색·필터 사용 가능
- HTML 저장: 본문·상태·휴지통·변경 기록이 담긴 **index.html** 다운로드
- JSON 백업 / 백업 불러오기: 전체 상태를 다른 기기에 옮기거나 복구. 불러오기 시 현재 내용을 백업 전체로 바꿉니다.

## 저장과 공통 배포본 업데이트

이 버전은 서버 데이터베이스 없이 동작합니다. 수정·삭제·복원은 접속한 브라우저에 저장되며, 다른 기기나 사용자에게 자동 공유되지 않습니다. 브라우저 데이터를 지우면 로컬 변경이 사라질 수 있으므로 HTML 또는 JSON 백업으로 보관하세요.

공통 배포본을 업데이트하려면:

1. 페이지에서 **HTML 저장**을 눌러 `index.html`을 내려받습니다.
2. 이 프로젝트의 `public/index.html`을 해당 파일로 교체합니다.
3. GitHub에 커밋하여 Vercel을 재배포하거나 CLI로 다시 배포합니다.

새 HTML에는 남아 있는 사례, 확인 상태 유형과 휴지통 상태가 포함됩니다. 영구 삭제한 사례의 본문·출처·변경 기록은 HTML/JSON에 포함하지 않습니다. 재등장을 막기 위한 사례 ID와 영구 삭제 시각만 남깁니다. 열람 화면에 있는 상태·자료 필터와 무관하게 전체를 저장합니다. 새 파일은 새 저장 식별자를 사용하므로 이전 브라우저 수정값이 새 배포본을 덮어쓰지 않습니다.

영구 삭제는 현재 브라우저 데이터와 이후 저장 파일에 적용됩니다. GitHub 원본·배포본과 이전에 받은 백업 파일은 자동으로 삭제되지 않습니다. 공통 배포본에서도 제거하려면 HTML 저장 후 재배포하세요. 영구 삭제 이후에는 이전 JSON으로 해당 사례를 복원할 수 없으며, 이전 백업을 확인하려면 삭제 이전 HTML을 사용하세요.

기존 버전의 브라우저 저장 및 JSON(스키마 2)은 자동으로 새 형식(스키마 3)으로 변환합니다.

브라우저에서 파일을 직접 열어도 사용할 수 있습니다. 브라우저 저장이 차단되면 안내가 표시되며 HTML/JSON 다운로드로 내용을 보관할 수 있습니다.

## 로컬 확인

`public/index.html`을 브라우저에서 직접 열거나, 이 폴더에서 `python3 -m http.server 8080 --directory public`을 실행해 `http://localhost:8080`으로 접속합니다.
